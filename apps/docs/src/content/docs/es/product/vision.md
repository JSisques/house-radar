House Radar es una plataforma de descubrimiento y análisis inmobiliario. Centraliza anuncios de diferentes fuentes, normaliza sus datos y permite buscar, comparar y seguir propiedades desde una única aplicación.

## Ámbito inicial

El ámbito inicial recomendado es **Galicia**, empezando por el área de **Santiago de Compostela**.

## Objetivo del MVP

Disponer de una base de datos inmobiliaria propia, alimentada mediante fuentes autorizadas, con:

- un buscador avanzado,
- fichas de propiedades,
- mapa,
- favoritos,
- e histórico de precios.

## Propósito del proyecto

House Radar es una herramienta personal construida con estándares de producto real. Sirve como portfolio y puede evolucionar a producto público (véase [D0](/es/adr/d00-project-purpose/)). Se espera calidad de producto desde el inicio: ADRs, tests, CI y observabilidad. El alcance del MVP se mantiene acotado: un usuario, Galicia, una fuente.
