## Context

The decision log was written before development started. It needed to state what kind of project House Radar is.

## Decision

A personal tool built to real-product standards; it serves as a portfolio and may evolve into a public product.

## Consequences

- Product quality from the start: ADRs, tests, CI, and observability.
- The MVP scope stays bounded: one user, Galicia, one source.
