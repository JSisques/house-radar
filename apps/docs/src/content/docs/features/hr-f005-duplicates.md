The same home can be advertised on several portals. House Radar must distinguish the real property from the listings published about it.

## Requirements

- [ ] Detection by external identifier.
- [ ] Detection by address or location match.
- [ ] Area comparison.
- [ ] Price comparison.
- [ ] Bedroom comparison.
- [ ] Detection of possible duplicates.
- [ ] Linking several listings to the same property.
- [ ] Ability to manually resolve doubtful matches.

## Notes

- **Recommended criterion:** in the first version, the system must flag probable matches and allow manual review. It is preferable not to automatically merge two different homes.
- Acceptance criteria and dependencies: to be defined in the detailed functional specification.
