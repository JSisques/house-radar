description: Template for new architecture decision records.
sidebar:
  order: 99
---

Copy this structure for each new decision. Keep the identifier consistent with the decision log.

```markdown
# D<number>. <Title>

- **Status:** Proposed | Accepted | Superseded
- **Date:** YYYY-MM-DD

## Context

What problem or situation motivates the decision?

## Decision

What was decided?

## Consequences

- What follows from this decision?

## Alternatives considered

- Only alternatives that were actually evaluated.
```
