- **Prioridad:** P1
- **Sección de origen:** 9

Vista agregada de los datos recopilados.

## Requisitos

- [ ] Número total de propiedades recopiladas.
- [ ] Número de anuncios activos.
- [ ] Número de anuncios nuevos.
- [ ] Precio medio de las propiedades.
- [ ] Precio mediano.
- [ ] Precio medio por metro cuadrado.
- [ ] Superficie media de las viviendas.
- [ ] Distribución por tipo de propiedad.
- [ ] Distribución geográfica.
- [ ] Evolución de precios de los anuncios recopilados.
- [ ] Estadísticas por municipio.

## Notas

- Las estadísticas deben indicar el tamaño y la procedencia de la muestra. Los precios anunciados no equivalen necesariamente a los precios reales de compraventa.
- Criterios de aceptación y dependencias: por definir en la especificación funcional detallada.
