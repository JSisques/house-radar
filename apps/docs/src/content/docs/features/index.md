Each functional area of the product draft (sections 1 to 12) has a page with an identifier, priority, responsible modules, dependencies, user stories, numbered business rules (`HR-FNNN-BRn`), Given/When/Then acceptance criteria (`HR-FNNN-ACn`), edge cases, scope limits, and open questions. Identifiers follow the `HR-F001` scheme proposed in the draft. Each feature can be turned into GitHub Issues with milestones and traceability between requirements, implementation, and releases. Decisions [D17 to D21](/adr/) record the product decisions taken during feature discovery.
