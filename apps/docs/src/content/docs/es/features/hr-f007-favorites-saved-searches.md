- **Prioridad:** P1
- **Sección de origen:** 7
- **Módulo responsable:** Por definir

Permite al usuario seguir propiedades y búsquedas de interés.

## Requisitos

- [ ] Marcar propiedades como favoritas.
- [ ] Consultar listado de favoritos.
- [ ] Eliminar favoritos.
- [ ] Guardar búsquedas con sus filtros.
- [ ] Editar búsquedas guardadas.
- [ ] Eliminar búsquedas guardadas.
- [ ] Consultar resultados de cada búsqueda.

## Notas

- Favoritos y búsquedas guardadas se asocian a un usuario, no son globales ([D13](/es/adr/d13-users-and-authentication/)).
- Criterios de aceptación y dependencias: por definir en la especificación funcional detallada.
