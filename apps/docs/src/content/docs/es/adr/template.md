---
title: Plantilla de ADR
description: Plantilla para nuevos registros de decisiones de arquitectura.
sidebar:
  order: 99
---

Copia esta estructura para cada nueva decisión. Mantén el identificador coherente con el registro de decisiones.

```markdown
# D<número>. <Título>

- **Estado:** Propuesta | Aceptada | Sustituida
- **Fecha:** AAAA-MM-DD

## Contexto

¿Qué problema o situación motiva la decisión?

## Decisión

¿Qué se ha decidido?

## Consecuencias

- ¿Qué se deriva de esta decisión?

## Alternativas consideradas

- Solo las alternativas que se evaluaron realmente.
```
