House Radar is ready for its first release when it meets these scenarios:

1. Listings can be ingested from at least one authorized source.
2. Listings are stored with a common data model.
3. Listings are updated periodically.
4. Possible duplicates can be identified.
5. Properties can be searched by combining multiple filters.
6. Properties can be viewed on a map.
7. The full property page and the original listing can be accessed.
8. A property can be saved as a favorite.
9. The price history can be consulted.
10. A search can be saved and run again.
11. It can be verified that the ingestion processes work correctly.

End-to-end tests are limited to these acceptance criteria ([D14](/adr/d14-testing/)).
