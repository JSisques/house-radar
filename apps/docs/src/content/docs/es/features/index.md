Cada área funcional del documento de producto (secciones 1 a 12) tiene una página con identificador, prioridad, módulos responsables, dependencias, historias de usuario, reglas de negocio numeradas (`HR-FNNN-BRn`), criterios de aceptación Dado/Cuando/Entonces (`HR-FNNN-ACn`), casos límite, límites de alcance y preguntas abiertas. Los identificadores siguen el esquema `HR-F001` propuesto en el documento. Cada funcionalidad puede convertirse en GitHub Issues con milestones y trazabilidad entre requisitos, implementación y releases. Las decisiones [D17 a D21](/es/adr/) recogen las decisiones de producto tomadas durante el descubrimiento de las funcionalidades.
