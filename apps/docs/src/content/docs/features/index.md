Each functional area of the product draft (sections 1 to 12) has a page with an identifier, priority, description, and requirements. Identifiers follow the `HR-F001` scheme proposed in the draft. Acceptance criteria, owning modules, dependencies, and edge cases will be detailed in the functional specification, so that each feature can be turned into GitHub Issues with milestones and traceability between requirements, implementation, and releases.
