## Principle

"Folla catastral" is a surveyor's data sheet, not a property showroom. Every datum has a source and a date; what was not measured is drawn as unmeasured land. It puts into the interface the product principle of not inventing information: a missing value is visible and distinguishable from a value that is zero or absent.

## Signature: unknown values are drawn

A value the source does not declare is not filled in or hidden. It is drawn with a cartographic hatch (135° lines, 1px every 8px, hatch token at 55% opacity so text over it stays legible, hatch token), a dashed border, and the texts "sin dato" and "no declarado" (translated per locale). It is never rendered as `—`, empty or zero, so "it has none" and "we do not know" stay distinct. In the app this is one shared component.

### History: "sin observar"

In the price history, the period before the first observation is drawn as a hatched "sin observar" area. The line starts where the first observation exists; nothing is extrapolated backwards.

- Líquen is scarce on purpose: only new items and price drops, always with dark text.
- Rises and errors use Ferruxe and never rely on color alone: an arrow or text always accompanies it.
- An approximate location is a dashed circle on the map, not a pin.

## Conflicts

When two sources disagree on an attribute ([D20](/adr/d20-listing-consolidation-rules/)), the attribute gets a Ferruxe border and names the other source's value, so the user sees both and the source of each.

## Accessibility

- Text and state colors keep sufficient contrast in light and dark; Líquen always carries dark text.
- Color is never the only signal: price changes and errors include an arrow or text.
- Unknown values are announced as text ("sin dato", "no declarado"), not conveyed only by the hatch.
- Fonts come from Google Fonts or are self-hosted, always with system fallbacks.

## Screens

The reference screens for the walking skeleton are:

- **Search:** filter rail, property results ("N anuncios, desde"), a map with "Buscar en esta zona" and approximate locations as dashed circles.
- **Detail:** data sheet grid, observed history, listings table and duplicate resolution.
- **Assisted import:** form with "El anuncio no lo dice", a map pin with precision, the detected municipality and a live preview.

Their canvas sources are versioned in [`apps/docs/design/folla-catastral/`](https://github.com/JSisques/house-radar/tree/main/apps/docs/design/folla-catastral). The live canvas is private; the versioned sources are the guide.
