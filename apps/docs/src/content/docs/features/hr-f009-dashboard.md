Aggregated view of the collected data.

## Requirements

- [ ] Total number of collected properties.
- [ ] Number of active listings.
- [ ] Number of new listings.
- [ ] Average property price.
- [ ] Median price.
- [ ] Average price per square meter.
- [ ] Average home area.
- [ ] Distribution by property type.
- [ ] Geographic distribution.
- [ ] Price evolution of the collected listings.
- [ ] Statistics by municipality.

## Notes

- Statistics must indicate the size and origin of the sample. Advertised prices do not necessarily equal actual sale prices.
- Acceptance criteria and dependencies: to be defined in the detailed functional specification.
