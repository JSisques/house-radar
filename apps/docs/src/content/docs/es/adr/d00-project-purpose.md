## Contexto

El registro de decisiones se redactó antes de empezar el desarrollo. Era necesario establecer qué tipo de proyecto es House Radar.

## Decisión

Herramienta personal construida con estándares de producto real; sirve como portfolio y puede evolucionar a producto público.

## Consecuencias

- Calidad de producto desde el inicio: ADRs, tests, CI y observabilidad.
- El alcance del MVP se mantiene acotado: un usuario, Galicia, una fuente.
