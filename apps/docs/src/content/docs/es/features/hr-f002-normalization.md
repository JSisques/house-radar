- **Prioridad:** P0
- **Sección de origen:** 2
- **Módulo responsable:** Por definir

Todos los anuncios deben convertirse a un modelo común, independientemente de su procedencia.

## Requisitos

### Información general

- [ ] Título del anuncio.
- [ ] Descripción.
- [ ] Precio.
- [ ] Superficie construida.
- [ ] Superficie útil.
- [ ] Superficie de terreno.
- [ ] Número de habitaciones.
- [ ] Número de baños.
- [ ] Tipo de propiedad.
- [ ] Estado de conservación.
- [ ] Año de construcción, cuando esté disponible.

### Características adicionales

- [ ] Garaje.
- [ ] Jardín.
- [ ] Piscina.
- [ ] Terraza.
- [ ] Balcón.
- [ ] Calefacción.
- [ ] Ascensor.
- [ ] Certificado energético.
- [ ] Tipo de suelo.
- [ ] Agua.
- [ ] Electricidad.
- [ ] Saneamiento.

### Procedencia y estado del anuncio

- [ ] Portal de origen.
- [ ] URL original.
- [ ] Identificador externo.
- [ ] Fecha de publicación, si se conoce.
- [ ] Fecha de incorporación a House Radar.
- [ ] Fecha de última comprobación.
- [ ] Estado del anuncio: activo, desaparecido o desconocido.

## Notas

- Los campos deben admitir valores desconocidos. La ausencia de un dato en el anuncio no significa que la propiedad carezca de esa característica.
- Conviene distinguir entre datos declarados por el anunciante, datos calculados y datos inferidos. Véase [Lenguaje ubicuo](/es/domain/ubiquitous-language/).
- Criterios de aceptación y dependencias: por definir en la especificación funcional detallada.
