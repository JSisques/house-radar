- **Priority:** P0

Each property will have its own detail page.

## Requirements

- [ ] Gallery of available photographs whose use is allowed.
- [ ] Title and description.
- [ ] Current price.
- [ ] Main features.
- [ ] Location.
- [ ] Built area and plot area.
- [ ] Price per square meter, when it can be calculated.
- [ ] Additional features.
- [ ] Original source.
- [ ] Link to visit the original listing.
- [ ] Date added.
- [ ] Last update.
- [ ] Available price history.
- [ ] Possible related duplicate listings.

## Notes

- The page shows the original source and a link to the original listing, which is part of the P0 scope.
- Acceptance criteria and dependencies: to be defined in the detailed functional specification.
