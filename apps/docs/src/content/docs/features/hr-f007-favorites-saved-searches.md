Let users keep track of properties and searches of interest.

## Requirements

- [ ] Mark properties as favorites.
- [ ] View the list of favorites.
- [ ] Remove favorites.
- [ ] Save searches with their filters.
- [ ] Edit saved searches.
- [ ] Delete saved searches.
- [ ] View the results of each search.

## Notes

- Favorites and saved searches are associated with a user; they are not global ([D13](/adr/d13-users-and-authentication/)).
- Acceptance criteria and dependencies: to be defined in the detailed functional specification.
